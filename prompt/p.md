# 各国护照处理 摆正角度和删除背景

## 环境

- 用conda环境env pdf 用pip不是pip3 用python 不是python3
- 图片样例在 img/ 目录下

## 输入

- 输入图片源目录 和 输出处理完的图片目录
- 输入源是护照每页的扫描图片文件 有的是横置的 有的是竖置的 还有可能歪斜
- 护照扫描时是整本摊开的 一张图会有两页
- 背景色大多是白色 由于扫描仪情况各异 会夹杂一些杂色 比如背景色偏黄 有杂质的情况下 背景会出现一些深色

## 处理

- 不要使用护照MRZ!! MRZ只有一页 扫描时前一次扫描可能是竖着放 下一页扫描可能是歪着放

## 输出

- 向输出目录输出处理后的图片
- 输出内容不因该包含护照的封皮 就是不处理护照的深色首页和底页
- 处理后的护照图片因该是两页摊开横置的 页码数字因该是竖着摆正 背景被剪切
- 护照角度可能需要微调 不是简单的90度调整
- 剪切护照外的背景 千万不可切到护照内容
